# fix-nested-face-create

A closed loop or circle drawn entirely inside one existing face created a face NESTED inside it — geometrically contained, topologically disconnected. Reported from a real session with sliver triangles and quads stranded inside a cage. The recognizer already knew it was less sure (it scored these at 0.4–0.5× confidence) but created anyway; a low-confidence create is still a create. Now withheld.
