# add-meshlet-target-path

Close task 2.2a — the last unmet v0.1 exit criterion — by first MEASURING what the existing indexed-vertex path does with 5M triangles on real hardware. The task assumes a meshlet/LOD pipeline is required; nothing has tested that, and the largest device measurement to date is 2.1M. The measurement selects between promoting the acceptance as-is, a meshlet path without LOD, or cluster LOD as its own change.
